Bem-vindo ao tutorial de Dart!
Este tutorial ensina como escrever código Dart construindo um
aplicativo interativo de linha de comando (CLI).

Você vai começar do zero: criando um aplicativo Dart em branco.
Ao final, você terá construído um app que demonstra os recursos
essenciais do desenvolvimento em Dart: variáveis, funções, classes,
programação assíncrona, testes e muito mais!

### Antes de começar {:.no_toc}

:::tip
**Parte da trilha de aprendizado de Flutter**

Este tutorial é o segundo passo da
[trilha de aprendizado de Dart e Flutter]({{site.flutter-docs}}/learn/pathway).
Se você quer aprender Dart e Flutter,
comece por lá!
:::

Este tutorial pressupõe que você tenha:

1. Um ambiente Dart configurado. Se não tiver,
   siga as instruções para [obter o Dart SDK](/get-dart).
2. Familiaridade básica com conceitos de programação. O tutorial
   é para iniciantes, mas não cobre os fundamentos da programação.
