Esta página lista o histórico completo de mudanças do
Dart SDK e da linguagem Dart, organizado por versão.
Usamos tags para classificar as mudanças, como
`New` para recursos, `Fixed` para correções de bugs e `Breaking` para mudanças incompatíveis.
Algumas mudanças são `Language versioned`,
o que significa que só têm efeito quando você
atualiza a [versão da linguagem](/language/versioning) do seu código.
