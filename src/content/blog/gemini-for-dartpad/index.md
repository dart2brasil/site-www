### O DartPad ganha um impulso do Gemini {:#dartpad-gets-a-gemini-boost}

<DashImage src="images/1nI_hhzL5l94Pvdtlzs32oA.webp" alt="DartPad com o logo do Gemini em um fundo escuro." />


Olá, desenvolvedores!

O DartPad é onde tantos de nós testamos ideias novas, aprendemos as nuances do Dart e do Flutter e experimentamos direto no navegador. Estamos animados para tornar esse processo ainda mais rápido e produtivo. Diga oi ao **Gemini no DartPad!** Agora você pode:

* Gerar código novo a partir de um prompt.

* Usar imagens, como mockups de UX e capturas de tela, para gerar código.

* Refatorar código existente a partir de um prompt.

* Sugerir correções de código para erros de análise e de tempo de execução.

Vamos conhecer em detalhes esses recursos novos e legais.

## Gerar código novo a partir de um prompt {:#generate-new-code-from-a-prompt}

Os usuários do DartPad agora podem usar o Gemini para gerar trechos de código Dart ou Flutter novos diretamente a partir de um prompt em linguagem natural.

<DashImage src="images/1fkZRgeIbh-ZiF2ETOn-uDg.webp" alt="Uma animação mostrando o Gemini no DartPad criando código Dart e Flutter a partir de um prompt em linguagem natural." caption="Crie código Dart e Flutter a partir de um prompt de IA" />


## Usar imagens para ajudar na geração de código {:#use-images-to-aid-in-code-generation}

Você também pode adicionar imagens aos seus prompts. As imagens podem ser usadas para ajudar na geração de código.

<DashImage src="images/1iGBCoFPCUhjawwPIJ0o6mQ.webp" alt="Uma animação mostrando um usuário enviando uma imagem ao Gemini no DartPad para gerar o layout de um app Flutter." caption="Use imagens para ajudar na geração de código" />


## Refatorar código existente a partir de um prompt {:#refactor-existing-code-from-a-prompt}

Além de gerar trechos inteiramente novos, o Gemini no DartPad pode ajudar você a iterar e modificar o código que já existe.

<DashImage src="images/1VtwjjXJKH_Ag0yFBcPZV1g.webp" alt="Uma animação do uso do Gemini no DartPad para refatorar um trecho de código existente." caption="Refatore código existente a partir de um prompt" />


## Sugerir correções para erros de análise {:#suggest-code-fixes-for-analysis-errors}

Partindo da capacidade que o DartPad já tem de exibir mensagens de diagnóstico do Dart Analyzer, integramos o Gemini para ajudar a resolver problemas que possam surgir no seu código. Se o seu trecho tiver erros marcados no painel de análise, basta selecionar o ícone do Gemini nesse painel, revisar a alteração sugerida e aceitá-la, se concordar.

<DashImage src="images/1N_XSofVUfkszjq-byDEAoA.webp" alt="Uma animação ilustrando o Gemini no DartPad sugerindo uma correção para um erro de análise estática." caption="Sugira correções para erros de análise" />


## Sugerir correções para erros de tempo de execução {:#suggest-code-fixes-for-run-time-errors}

O DartPad também pode sugerir correções para erros de tempo de execução.

<DashImage src="images/1Ej5VLgICUX-WYgBhQgydhg.webp" alt="Uma animação mostrando o Gemini no DartPad oferecendo uma solução para corrigir uma exceção em tempo de execução." caption="Sugira correções para erros de tempo de execução" />


## Para concluir {:#in-conclusion}

O DartPad está focado em encontrar formas de reduzir a barreira para testar ideias novas e aprender mais sobre Dart e Flutter. Nossa nova integração com o Gemini é mais um passo nesse caminho e facilita ainda mais para você experimentar e explorar. Mal podemos esperar para ver o que você vai criar!
