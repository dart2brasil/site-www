O [Google Summer of Code](https://summerofcode.withgoogle.com/) (*GSoC*) é um programa global focado em trazer estudantes de desenvolvimento para o desenvolvimento de software open source. Os estudantes são patrocinados pelo Google para trabalhar, durante o verão, com uma organização open source mentora em um projeto de programação de 3 meses. Nos últimos 15 anos, mais de 15.000 estudantes participaram do Google Summer of Code.

Este ano, temos o prazer de anunciar que o [Dart é uma organização mentora](https://summerofcode.withgoogle.com/organizations/6544944065413120/) no Google Summer of Code 2020.

## Você tem interesse? {:#are-you-interested}

Comece agora lendo [a lista de ideias de projeto](https://github.com/dart-lang/sdk/wiki/Dart-GSoC-2020-Project-Ideas) para encontrar algo que combine com suas habilidades e interesses. Embora as inscrições formais [abram em 16 de março](https://summerofcode.withgoogle.com/how-it-works/), você já pode discutir e adaptar ideias de projeto com possíveis mentores hoje.
> A equipe do Dart só espera ter mentores suficientes para aceitar um punhado de inscrições. Então, não deixe de conferir [as outras organizações mentoras](https://summerofcode.withgoogle.com/organizations/) do Google Summer of Code 2020.

Se você tiver dúvidas específicas sobre Dart e GSoC, pergunte na [nossa lista de discussão dedicada](https://groups.google.com/forum/#!forum/dart-gsoc).
