[Google Summer of Code](https://summerofcode.withgoogle.com/) (GSoC) é um programa global que incentiva estudantes de programação a entrar no desenvolvimento de software open source. Os estudantes são patrocinados pelo Google para trabalhar, junto com uma organização open source que atua como mentora, em um projeto de programação de 12 semanas ou mais durante o verão. Nos últimos 17 anos, mais de 18.000 estudantes participaram do Google Summer of Code.

Temos o prazer de anunciar que o Dart é uma organização mentora (pela terceira vez!) no Google Summer of Code 2022. Confira os posts com os resultados para saber mais sobre os ótimos projetos de [2020](/blog/google-summer-of-code-2020-results) e [2021](/blog/google-summer-of-code-2021-results).

### Você tem interesse? {:#are-you-interested}

Comece agora lendo [a lista de ideias de projetos](https://github.com/dart-lang/sdk/wiki/Dart-GSoC-2022-Project-Ideas) para encontrar algo que combine com as suas habilidades e interesses. As inscrições formais devem ser enviadas até 19 de abril, mas quem está pensando em se inscrever é incentivado a enviar rascunhos antecipados e pedir feedback.
> A equipe do Dart espera ter mentores suficientes para aceitar apenas um punhado de inscrições, então também confira as [outras organizações mentoras](https://summerofcode.withgoogle.com/organizations/).

Se você tiver dúvidas específicas sobre o Dart e o GSoC, pergunte na [nossa lista de discussão dedicada](https://groups.google.com/g/dart-gsoc).
